# Instructions for AI Agents

## Overview

Credentials management utilities shared by the [RabbitMQ](https://www.rabbitmq.com/) Java libraries
(token refresh, OAuth 2 client credentials support).

This library is meant only for the RabbitMQ Java libraries (e.g. the AMQP 1.0 Java client and the stream Java client).
Its API is not public and not considered stable.

## Supported Java Versions

This library supports Java 8+.
Main and test code must compile with `--release 8`: do not use Java 9+ APIs.

## Build

```bash
./mvnw clean test-compile
```

## Sanity Check

```bash
./mvnw test-compile
```

### Running Tests

Tests do not need any external service:

```bash
./mvnw verify
```

To run a single test:

```bash
./mvnw test -Dtest=TokenCredentialsManagerTest
```

## Repository Layout

* `src/main/java/com/rabbitmq/client/credentials`: credentials manager contract and token refresh
* `src/main/java/com/rabbitmq/client/credentials/oauth2`: OAuth 2 support
* `src/test/java`: tests

## Key Files

Under `src/main/java/com/rabbitmq/client/credentials/`:

* `CredentialsManager.java`: contract to authenticate and re-authenticate components (e.g. connections)
* `TokenCredentialsManager.java`: credentials manager that requests and refreshes tokens
* `oauth2/HttpTokenRequester.java`: OAuth 2 token requester over HTTP(S)
* `oauth2/GsonTokenParser.java`: OAuth 2 token response parser

## After Completing a Task

### Iterative Reviews

After completing a task, perform up to twenty iterative reviews of your changes.
In every iteration, look for meaningful improvements that were missed, for gaps in test coverage, and for deviations from the instructions in this file.

If no meaningful improvements are found for three iterations in a row, report it and stop iterating.
